# Security Policy

## Supported Versions

| Version | Supported |
| --- | --- |
| `main` / latest | :white_check_mark: |

## Reporting a Vulnerability

Please use GitHub Security Advisories with private vulnerability reporting enabled for this repository when you discover a security issue. That keeps the report private while maintainers investigate and coordinate a fix.

When submitting a report, include as much detail as possible:

- A clear description of the issue and affected area
- Reproduction steps or a proof of concept
- Expected impact and any known mitigations
- Logs, screenshots, or traces that help explain the problem

Please do not open public issues for suspected vulnerabilities until the maintainers confirm a fix has been released.

## Response Expectations

The project aims to:

- Acknowledge new private vulnerability reports within 5 business days
- Provide an initial triage or status update within 10 business days
- Share remediation guidance or a target fix plan as soon as the issue is validated

Response times may vary with maintainer availability, but private reports will be handled as quickly as practical.
