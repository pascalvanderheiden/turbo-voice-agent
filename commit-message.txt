feat(infra): single-step azd deploy via idempotent preprovision param collection

Adds infra/scripts/collect-deployment-params.sh which auto-discovers
subscription, tenant, and signed-in principal from az CLI; prompts once
for optional params (custom domain, cert name, client secret); and
persists all values via `azd env set`. Idempotent: subsequent runs skip
prompts entirely. CI-safe: fails fast when required vars missing under
GITHUB_ACTIONS=true.

- New infra/scripts/collect-deployment-params.sh (orchestrator, first in preprovision)
- setup-entra-app.sh now writes ENTRA_CLIENT_ID/TENANT_ID back to azd env
- azure.yaml preprovision order: collect-params → select-regions → setup-entra
- README Manual Deployment collapses from 7 steps to 3 (login + azd up)
- Generalizes the quota-region picker idempotency pattern
